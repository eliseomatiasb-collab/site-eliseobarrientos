# eliseobarrientos.com.br

Site estático (HTML/CSS/JS puro) de Eliseo Barrientos, Engenheiro Civil (CREA 2619733995) e Corretor de Imóveis (CRECI 239602-F).

- `index.html` — home com a carteira de imóveis (dados no array `P` dentro do arquivo)
- `imoveis/*.html` — uma página por imóvel
- `img/` — fotos otimizadas (capa 1400px 16:9, galeria 900px 3:2)
- `vercel.json` — URLs limpas e cache de imagens

Deploy: Vercel (deploy automático a cada push na branch `main`).
